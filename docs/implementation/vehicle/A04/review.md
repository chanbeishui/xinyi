## 已核实的权限与责任边界

- 公司档案读写分别校验当前真实 ADMIN、对应功能权限及权威公司范围，空集合关闭。归属写入另需 `biz:driver:assigncompany`，原、新归属的维护与归属范围均需覆盖；目标不存在、停用或删除拒绝。NULL 无法借部门或账户请求字段认领。
- 跨公司转移先锁司机，再核对全部占用、未结束承接及 WAIT_RESPONSE 邀约，任一存在即拒绝；成功转移只改变公司并关闭新增承接，不修改资格结论、本人听单、历史任务、保管或资金。
- 原先历史权限误要求 assignment 范围再次覆盖司机公司；主任务发现后已修正。司机详情按 query 的公司范围，承接行、total、归还数和当前承接 ID 按原订单 `dept_id` 的 assignment 范围单独过滤。只有本站历史权限的合法人员不因缺少公司根节点的 assignment 权限被拒绝；同公司别站及其他公司历史均不泄露。无权编号隐藏，真实 occupied 保留。
- 原先未核验遗留 phone_cipher 可能进入脱敏；主任务发现后 Mapper 只投影 `phone_verified_at` 非空的密文。手机号搜索使用已核验 HMAC 精确查询；姓名字段是昵称，score 无可信来源时返回 NULL，不冒充实名或评分。
- ADMIN 专用链仅匹配 `/api/admin/drivers` 及其子路径；MINI Token 或伪造 X-Client-Type 不能获得后台权限，认证失败为真实 HTTP 401。每次数据库读取当前 auth_version，目录守卫与写事务串行，Redis 删除失败不延迟撤权。

## 状态、并发与审计

PATCH 仅接受版本、原因、运营备注和显式归属；资格、证件、听单、占用、金额和内部数据范围均不可绑定。暂停/恢复使用独立功能权限及版本、UUID 幂等键。资格、准驾、证照或复审不允许恢复时为 `409/VI_STATE_CONFLICT`；目标公司无效为 `422/VI_DATA_INVALID`，不混为请求格式错误。

恢复要求 APPROVED、账号与安全状态有效、明确准驾类别、有效期限或显式长期标记、明确且未来的复审截止，以及有效归属。证照按上海日历日包含到期当日，复审按精确 UTC 时刻判断。旧 IdentityReadMapper 的身份角色判定未被本任务静默改写；行政新承接判断独立于 DRIVER 视角。暂停后新会话仍读取原资格与既有责任，不清邀请码、承接、资源占用、预约额度或实收/预留/已退金额。

目录守卫、账号版本、司机行锁、CAS、幂等、成功审计与 outbox 在同一事务；幂等仅缓存记录 ID，返回时重读授权后的事实。同键同体不重复写，异体冲突；数据库约束与 outbox 故障整笔回滚，拒绝审计使用独立事务保留。

备注变更的原因及前后备注按 `A04:ADMIN:{userId}:DRIVER_EDIT:{driverId}` 绑定 AES-GCM envelope；启停原因绑定各自成功动作与记录 ID。审计正文固定脱敏，outbox 和幂等结果不含自由文本；授权详情可读取运营备注，但不能取回内部操作原因或密文。补强用例已在最终全量实际核对解密、错动作/记录拒解、同键一次及无明文泄露；实际报告与归档已独立核对。

## 用户确认与实现

用户确认由车主从可用站点中选择，地图使用腾讯位置服务。新增POST /api/app/owner/orders/stations查询候选；原POST /api/app/owner/orders/quote增加必填stationId，服务端重新核实。没有自动取第一站或按最低价决定站点。小程序顺序为时段→地址→车辆/检测类型→选站→核对报价。

候选只读取公开站点信息，输入资料必须属于真实MINI/OWNER账户。本人记录ID与临时草稿严格二选一，支持车辆/地址四组合；伪造归属、金额、内部字段或非OWNER身份拒绝。报价owner_account_id是权威归属；站点归属vi_station.dept_id。临时草稿不写车辆库/地址簿，无隐藏保存。

以B01真实锚点的起止时间查找用户选站的PICKUP，并核验车型和启用状态。半径采用保守驾车路线距离上限；未以直线距离冒充计费路线。到站区间由上门区间+交接耗时+地图行车时间+缓冲计算，须完整落入唯一有效STATION_RECEIVE区间。双方均有余量才能报价；候选、报价、幂等重试均不占额度、不建订单。

腾讯HTTPS驾车规划使用GCJ02纬度,经度顺序，distance为米，duration为分钟，向上转换为秒。缺密钥、失败、重定向、非法距离或响应不完整均拒绝，不能生成0元或虚假路线。正式端点固定腾讯HTTPS；只允许local/test/integration环境使用本机HTTP协议替身。外部调用在业务事务外，不记录密钥、坐标、请求URI或响应正文。官方参数参考：[腾讯路线服务说明](https://github.com/TencentLBS/tencentmap-webservice-skill/blob/main/references/api-direction.md)。

保存前在目录/账户/站点及配置锁保护下重新加载输入、站点、两时段、价格哈希和配置版本；变化返回冲突。金额由C04唯一已审核版本的整数计算器产生。vi_quote保存真实选站、双时段、路线和完整计价/协议快照；地址、坐标及原请求密文保存。JSON明细包含items、price、ruleContent、policy、输入HMAC及加密请求，B03不能将其当裸明细数组读取。

幂等重放先查既有结果，不重新调用地图；之后仍检查所属账户、使用状态、有效期、资料和配置版本。报价、成功审计、outbox及幂等完成同事务，失败整体回滚，失败审计独立保留。validateForOrder供B03在锁定报价和容量的建单事务中再次校验；此方法本身不预占、不消费报价，不代表B03已经实现。

小程序查询后不预选站点，必须由用户点击；正式报价显示选站、分项费用、总额及北京时间有效期。修改资料或返回上一步清空旧报价，丢弃异步旧响应；网络故障重试原意图沿用原幂等键。明确过期、配置变化或不可服务时退回重新查询，避免永久重放失效报价。

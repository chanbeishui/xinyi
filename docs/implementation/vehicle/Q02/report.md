## 权限、隐私与事务

所有五接口只接受真实ADMIN；MINI、缺登录、伪造请求头不能成为后台主体，认证失败真实HTTP401。列表、详情、创建、编辑、发布五个功能权限各自与公司范围校验，空范围失败关闭；详情越权按404隐藏。创建非法/停用/已删除公司沿IntegrationAuthority既有语义403 VI_FORBIDDEN，未为凑测试更改公共授权服务。

题目与媒体的权威归属来自数据库父课程。文件创建/完成还须各自uploads功能范围和trainingcourse:edit范围同时覆盖公司；元数据/读取须files功能范围与trainingcourse:query范围均覆盖。课程绑定/发布内部验证仍校验文件功能范围，不能只查课程权限。派生须源query与目标create、文件范围都满足；公司不能通过PUT迁移。公司选择器复用真实/system/dept/list，另需system:dept:list；框架HTTP200但code拒绝不能当目录成功。

只有后台query及公司范围的详情返回标准答案；列表与缺query的写响应只返摘要，主API将Summary/Detail明确分开。含答案内容使用有密钥HMAC指纹，不用可离线枚举小答案空间的裸SHA；不得在Q03学员投影下发此摘要。维护原因AES-GCM并以ADMIN/课程/动作AAD绑定，审计摘要无题干/答案/自由原因明文，outbox及幂等结果只含安全ID/版本。

统一目录守卫、实时auth_version、父课程/族、文件锁、CAS、幂等、业务写入、成功审计与outbox在同事务。幂等只存目标ID，重放重新读取权限；并发保存/发布/派生不重复成功，数据库/outbox/密钥错误整体回滚。撤权与排队写操作串行，旧Token不能依赖Redis删除是否成功继续操作。课程业务不改用户角色或auth_version，真实角色调整仍由统一授权服务执行。

## 真实私有媒体

F01新增TRAINING_MEDIA＋trainingId，只允许ADMIN当前公司DRAFT父课程，video/mp4不超过100MiB。原JPEG/PNG用途仍10MiB与原权限；证件、订单附件、其它课程或未READY媒体不能冒充教材。发布后不能再签新票、rawPUT或complete改写原件，合法原媒体保留授权读取。

实际字节校验包括MP4盒边界/深度/计数、ftyp/moov/mdat、H264视频配置、可选AAC-LC的esds对象/音频配置、非零真实时长/尺寸及流式SHA256；只把最多8MiB的moov交解析器，其余64KiB流处理，100MiB不会整体进入Java堆。支持普通及合法fragmented容器，结构校验不宣称逐帧解码、运营教材合规或防作弊认证。使用[MP4 parser官方项目](https://github.com/sannies/mp4parser)的isoparser1.9.56，依赖正常由Maven解析，没有提交缓存jar。

后台上传、读取均固定同源传输路径、真实ADMIN会话及短票，不把Token或对象键发外部地址。视频UPLOAD申请票/传输租约/READ票均300秒，PC视频请求300秒；图片原传输租约和读取60秒。媒体缺对象409保留UPLOADING可续传，存在却大小/内容不符才422，不因用户尚未传输就永久reject。

下载为同步200完整原始流，精确Content-Type:video/mp4、不带字符编码，no-store/nosniff；不宣称Range/断点续传。首字节前在授权事务写FILE_MEDIA_DOWNLOAD_STARTED，失败不发送原件；完成后另写真实完成事件，传输前后及每1MiB重新检查会话/范围/票据/元数据。中途撤权不能承诺收回已授权输出的字节，开始与完成轨迹分别反映真实结果。

PC支持真实MP4字节上传、核验、私有原片预览，保存/发布未知结果锁住原body/UUID，409保留输入但要求重读，身份或403清除旧题库、私有预览与在途响应。标准答案和票据不落本地持久化；服务端仍再次验证，UI按钮不作为权限依据。

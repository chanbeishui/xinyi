# 全库代码排版与注释检查

按用户反馈进行了全库静态扫描，并人工抽查支付、第三方配置、报价/计价、订单、前端页面和测试。确认近期新增代码存在明显可读性问题；主要原因是实现与提交过程未把可读性作为交付检查项，不能归因于编辑器显示。

## 检查范围和证据

全量扫描覆盖1,194个Git管理或未忽略的文本源码文件，包含Java、Vue、TS/JS、SQL/XML、脚本、样式、生成模板和资料包工程工具；依赖、构建产物、私有运行文件排除。静态资源/模板34份、资料与工具224份单列。清单见all-source-scan.json，可运行`python3 bin/audit_readability.py --output /tmp/xinyi-readability.json`复查。

初始业务源码基线为926份六类文件，见before-core.json；该基线与补充扫描范围不同，不能用文件总数差异计算整改比例。这是全量静态扫描与重点人工抽查，不代表已逐行审查全部业务语义。

## 原因和具体表现

1. **写入代码时过度压缩。** 新增Java方法包含连续赋值、校验、Mapper写入、审计和返回，常被写在同一行；Vue模板与CSS也被串成一行。第三方配置IntegrationService最长行1,545字符；PaymentConfiguration为1,174，PaymentService为1,095。既有平台SysConfigServiceImpl则按方法、语句和分支正常展开。由实际源码确认是写法问题。
2. **复杂度没有通过结构表达。** 事务lambda内再嵌幂等lambda，多层分支使用短变量名。仅自动换行仍可能产生深缩进，不能代替方法拆分与有意义的命名。本轮关闭意图已拆成独立私有方法；其他历史服务仍需逐项整理。
3. **对注释规范执行过窄。** 原AGENTS要求“中文，且只在逻辑不直观时添加”，并未禁止必要说明。支付/配置等核心代码里，锁顺序、原交易身份、关闭竞争和晚到付款恰恰属于必须解释的逻辑；此前省略是执行不到位。部分DTO/getter没有注释可以接受，资金与权限分支缺少约束说明不能用这个理由解释。
4. **缺少提交前约束。** 检查隐藏文件、Maven/前端脚本和Git hooks，没有发现已启用的Prettier、Checkstyle、Spotless或格式检查；现有hook是工具跟踪用途。测试验证了业务行为，没有验证排版与关键规则是否可读，我也没有补上人工可读性复核。
5. **生成文件放大了长行数字。** 小程序api/types.ts有一行3,250字符的契约类型声明，文件标明Generated；应从生成流程统一改善，不能和手写支付逻辑压成一行等同处理。历史资料包工具也有紧凑代码，需要单独整理，不能据此为新业务代码沿用紧凑排版辩护。

## 本轮已整改

只整理本轮支付相关源码与测试，没有宣称全库历史文件均已修复。12个Java文件、付款API和页面、新增支付生命周期XML共15个文件展开；既有PaymentMapper仅保留本轮字段变更。逐文件前后记录见payment-changes.json。

- PaymentLifecycleService：116行展开为608行，最长行794降至100；关闭意图分为命名私有方法，保留事务和幂等边界。
- PaymentService：66行展开为478行，最长行1,095降至100；补充会话复核、关闭意图阻断预支付、原商户单号/截止时间的约束。
- PaymentConfiguration：37行展开为296行，最长行1,174降至100；说明当前策略、历史收款身份和凭据轮换的区别。
- 小程序付款页：114行展开为414行，最长行851降至97；模板、样式和异常处理展开，说明客户端回调不能作为资金成功依据。
- 补充渠道永久去重、额度两份凭证原子迁移、查单短租约、网络事务边界、晚到付款冲突、退款预留额和ACK条件等中文注释。普通访问器不堆叠重复注释。

Java使用临时google-java-format 1.27.0 AOSP格式（[官方版本](https://github.com/google/google-java-format/releases/tag/v1.27.0)），前端使用临时Prettier 3.6.2，未增加应用运行依赖。通用XML格式器试验会拆开MyBatis实体运算符，已撤销该结果，改按SQL子句排版并核对动态标签、参数和SQL token等价。其余Java除关闭意图方法拆分外，去掉注释/空白后的词法单元一致。

根AGENTS新增可读性交付要求，`.editorconfig`补充Java四空格、Vue/TS两空格等基础规则，新增扫描脚本。**尚未接入全仓库强制格式CI**；编辑器配置和统计脚本不能宣称已建立完整自动质量门禁。

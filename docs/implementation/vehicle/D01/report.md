- 公司听单配置专页 B24-listening-company：明确选择真实公司，读取和维护分别验证功能权限与公司范围；无主部门默认值、无生产运营参数默认值。保存带独立 CAS、UUID 和变更原因，成功后立即生效。
- MINI D06 工作台：当前资格、行政许可、听单意愿、有效截止、在手占用、位置/精度、最近认证交互分别显示。服务数量来自本人已结束且 RETURNED 的真实任务，可含本人原公司历史，不返回订单详情。
- 六个实际接口：本人 availability/listening/location/presence 以及公司 listening-config GET/PUT。Controller 放在荣利 dispatch 业务域；只有 ADMIN 安全链装配位于启动模块。
- 每次开启固定上海业务日及 UTC 截止；请求绑定观察到的日期、本人真实会话、身份上下文、公司 epoch、配置版本和独立听单版本。昨日未送达或未知结果的开启请求不能漂移到今日，同 UUID 重放不延期。
- 固定到期 outbox、补缺和真实关闭服务。旧计时器不能关掉后来手动开启的新窗口；旧裸 enabled 没有可信截止时拒绝作为有效听单，统一服务安全关闭，保留历史事实。

- 最近位置只保留一个加密点，独立记录采集/接收时间、精度和真实会话归属。GCJ02、有限数值、严格 UTC 时间、偏差及乱序均校验；有效期按采集和接收较早时刻起算。GET 不续期，同键重试不续期。

## 配置与数据权限

权威归属是数据库代驾档案的真实公司；本人接口由 MINI 账号反查唯一档案，不接受客户端 driverId、ownerDeptId 或权限字段。公司配置以显式目标公司和独立 query/edit 范围校验，空范围拒绝。旧 Token、旧 session/context、迁移前公司 epoch 即使重放也重新鉴权。

配置项为严格 HH:mm（Asia/Shanghai）、位置有效秒数与最近交互有效秒数（31–86400）、精度上限米（1–100000）、前台采点间隔秒（30–3600，且小于两种有效期）。30 秒是本系统节流规则，不冒称微信固定频控。原因去首尾空白后 1–500 字，独立 AAD 加密留审计，GET/outbox 不含原因明文。

目录守卫、真实身份/会话、档案、配置、定位/交互按统一顺序在事务中处理；权限、CAS、业务写入、成功审计和 outbox 同事务。拒绝另有审计；Redis 强退失败不能恢复已撤销权限。关闭听单不改角色、行政许可、资格、邀约、承接、占用或车辆责任，D01 不直接修改授权表。管理员详情也按实际截止显示听单，不把缺少 MINI 会话上下文的后台视图当可派单证明。

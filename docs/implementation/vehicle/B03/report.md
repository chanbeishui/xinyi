## 实现和权限

只接受本人quoteId、当前服务/隐私协议版本、主动同意及备注；地址、车辆、金额、站点、部门均来自服务端已校验快照。必须已核验手机号。订单归属站点真实部门，收款归属该部门层级唯一配置的公司；两个归属分别保存，客户端不能指定。事务内再次核验DB会话、上下文和安全代际，防止在等待锁期间已退出的旧请求继续写入。

锁定报价与双时段，重新校验配置和余量后，同时创建PENDING_PAY订单、PENDING/UNSELECTED付款记录、两条HELD凭证、私有及协议快照，消费报价，写ORDER_CREATE审计和ORDER_CREATED outbox；任一步异常整体回滚。截止统一为数据库UTC创建时刻+30分钟，距上门不足完整窗口则拒绝。QUOTE消费与唯一键阻止换键重复下单。同键同体重放已有订单，缓存只含orderId，不含明文地址或备注。失败/越权审计不含密钥、手机号或备注。

B02容量指纹改为实际额度配置内容；其他订单占额引起版本递增时，只要仍有余量可继续使用已有报价。资料、价格、协议或额度配置改变仍要求重新报价。订单临时车辆vehicleId为null，契约、三份类型及所有引用切片同步；不自动保存常用车辆/地址。

支付采用现有integration已发布指针/校验/发布记录。未发布、缺失、重复公司、错误环境、双关或无可用方法均在占额前拒绝。微信依赖校验同公司/环境/真实AppID，线下资料和凭据槽位受控；未实现配置发布页面或供应商适配器的部分仍属于X01/X02/P01，不因本轮测试种入显式发布夹具而标为完成。

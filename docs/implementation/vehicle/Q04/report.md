## 人工确认、权限与审计

候选来自当前DRAFT/REJECTED申请和数据库有效公司，不允许手填版本/部门。BACKGROUND与LICENSE分别登记PASSED/FAILED及可空普通备注，无附件、报告、标准发布或第三位复核人要求。经办与复核必须为两位有真实同公司权限的ADMIN；申请人本人不得经办/复核。历史员工关联及可信手机号匹配到的后台用户在登记时冻结，换号或撤关联不能抹除自审约束。

读取按原记录owner公司过滤，列表不解密备注；详情另需query。人工写入分别校验create/review与query及各自公司范围，复核再核当前申请、材料和公司epoch；设备封存按close及原公司范围，返回的仅为安全动作元数据，不额外冒用query权限。空权限范围失败关闭，不靠主部门、列表可见或前端隐藏按钮授权。所有内部发布入口也锁定统一授权目录并重验auth_version，旧Token不依赖Redis删除成功。

CONFIRM同事务终结人工事实、发布对应可信PASSED/FAILED并链接proof；RETURN不发proof。已终结不可编辑，重新经办创建新行；待复核同申请/epoch/材料/类型唯一。复核人允许参与后续Q05最终资格审核。普通备注AAD绑定实际数据库ID与贡献者，空备注按JSON字符串认证加密；权限、写入、CAS、幂等、成功审计/outbox同事务，故障整体回滚。幂等只存记录ID，不缓存敏感明文，重放仍重鉴权。

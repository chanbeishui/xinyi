# 数据模型与字段字典 V6.4
共 79 个参考业务表；不是实际数据库执行记录。主源为data_model_V6.4.json。已有实现须比对并前向适配，不执行全量初始化覆盖真实库。

## vi_account · 微信统一基础账户
角色是账户扩展资格，不按客户端role直接建高权身份；新号只有OWNER；AppID/OpenID不由客户端指定；普通联系人号码不是身份号码。
主键：id；ID策略：MYSQL_AUTO_INCREMENT
|字段|SQL类型|含义|
|---|---|---|
|`id`|`BIGINT NOT NULL AUTO_INCREMENT`|数据库AUTO_INCREMENT生成内部Long；API输出十进制字符串|
|`app_id`|`VARCHAR(64) CHARACTER SET ascii COLLATE ascii_bin NOT NULL`|微信应用标识|
|`open_id`|`VARCHAR(128) CHARACTER SET ascii COLLATE ascii_bin NOT NULL`|同一小程序身份|
|`union_id`|`VARCHAR(128) CHARACTER SET ascii COLLATE ascii_bin NULL`|仅供应商可信返回时记录|
|`phone_cipher`|`VARBINARY(512)`|手机号密文|
|`phone_lookup`|`BINARY(32)`|带密钥摘要，非裸哈希|
|`nickname`|`VARCHAR(100)`|选填昵称|
|`status`|`VARCHAR(24) NOT NULL`|AccountStatus: ACTIVE,LOCKED|
|`privacy_version`|`VARCHAR(64)`|最近同意版本|
|`avatar_file_id`|`BIGINT NULL`|本人已验证头像引用，不直接存URL|
|`phone_verified_at`|`DATETIME(3) NULL`|服务端最后一次可信手机号验证UTC时刻|
|`phone_source`|`VARCHAR(24) NULL`|PhoneProofSource: WECHAT,SMS；仅WECHAT可触发新员工关联|
|`employee_auto_link_blocked`|`TINYINT NOT NULL DEFAULT 0`|管理员解除后阻止该账号自动换绑；仅后台明确恢复，可不影响车主|
|`created_at`|`DATETIME(3) NOT NULL DEFAULT (UTC_TIMESTAMP(3))`|创建时间，统一UTC|
|`updated_at`|`DATETIME(3) NOT NULL DEFAULT (UTC_TIMESTAMP(3))`|UTC更新时间；Mapper每次修改显式SET updated_at=UTC_TIMESTAMP(3)，不依赖连接时区|
|`version`|`BIGINT NOT NULL DEFAULT 0`|乐观锁版本|

```sql
UNIQUE KEY uk_app_open (app_id,open_id)
KEY ix_phone_lookup (phone_lookup)
CONSTRAINT ck_ver_account CHECK (version >= 0)
CONSTRAINT ck_592d8ece9c CHECK (`status` IN ('ACTIVE','LOCKED'))
CONSTRAINT ck_87f78b0fed CHECK (`phone_source` IN ('WECHAT','SMS'))
```

## vi_employee_binding · 微信账户与框架员工受控绑定
可信微信手机号唯一匹配有效sys_user自动建立，无员工申请；同应用每账号/每员工至多一个未撤销关联。暂停仍占唯一关系；撤销写永久留痕及防重绑标记；复核修复后须本人新手机号核验，不允许后台直接填openid。关联、权限版本、audit/outbox同事务。
主键：id；ID策略：MYSQL_AUTO_INCREMENT
|字段|SQL类型|含义|
|---|---|---|
|`id`|`BIGINT NOT NULL AUTO_INCREMENT`|数据库AUTO_INCREMENT生成内部Long；API输出十进制字符串|
|`account_id`|`BIGINT NOT NULL`|关联vi_account|
|`sys_user_id`|`BIGINT NOT NULL`|引用现有sys_user，不重建员工|
|`bound_by`|`BIGINT NULL`|自动关联为NULL，操作者为系统；管理员后续操作单独审计，绝不填假管理员|
|`bound_at`|`DATETIME(3) NOT NULL`|绑定时间|
|`revoked_at`|`DATETIME(3)`|解除时间|
|`active_account`|`BIGINT GENERATED ALWAYS AS (IF(revoked_at IS NULL, account_id, NULL)) STORED`|有效或暂停关联占用；只读生成列|
|`active_user`|`BIGINT GENERATED ALWAYS AS (IF(revoked_at IS NULL, sys_user_id, NULL)) STORED`|有效或暂停关联占用；与app_id联合唯一|
|`permission_version`|`BIGINT NOT NULL DEFAULT 0`|员工关联权限版本；撤权事务更新|
|`app_id`|`VARCHAR(64) CHARACTER SET ascii COLLATE ascii_bin NOT NULL`|关联应用命名空间|
|`source`|`VARCHAR(32) NOT NULL DEFAULT 'WECHAT_PHONE_MATCH'`|EmployeeLinkSource: WECHAT_PHONE_MATCH|
|`status`|`VARCHAR(24) NOT NULL DEFAULT 'ACTIVE'`|EmployeeBindingLifecycle: ACTIVE,SUSPENDED,REVOKED|
|`phone_lookup`|`BINARY(32) NOT NULL`|关联时一致的规范化手机号HMAC；不是可还原裸手机号|
|`last_phone_verified_at`|`DATETIME(3) NOT NULL`|最近本人微信手机号核验时间|
|`employee_auth_version`|`BIGINT NOT NULL`|建立关联时的框架授权版本快照；每次工作请求仍检查当前员工状态和权限|
|`auto_rebind_blocked`|`TINYINT NOT NULL DEFAULT 0`|管理员撤销后拦截同应用同员工新自动关联；明确allow-rematch才解除|
|`suspended_reason`|`VARCHAR(64) NULL`|手机号变更、账号停用等失效原因；不泄漏其他账号|
|`revoked_by`|`BIGINT NULL`|后台受控撤销操作者|
|`revoked_reason`|`VARCHAR(500) NULL`|解除依据|
|`created_at`|`DATETIME(3) NOT NULL DEFAULT (UTC_TIMESTAMP(3))`|创建时间，统一UTC|
|`updated_at`|`DATETIME(3) NOT NULL DEFAULT (UTC_TIMESTAMP(3))`|UTC更新时间；Mapper每次修改显式SET updated_at=UTC_TIMESTAMP(3)，不依赖连接时区|
|`version`|`BIGINT NOT NULL DEFAULT 0`|乐观锁版本|

```sql
UNIQUE KEY uk_active_account (active_account)
UNIQUE KEY uk_active_user (app_id,active_user)
KEY ix_employee_link_phone (phone_lookup)
KEY ix_employee_link_block (app_id,sys_user_id,auto_rebind_blocked)
CONSTRAINT ck_ver_employee_binding CHECK (version >= 0)
CONSTRAINT ck_0322202dab CHECK (`source` IN ('WECHAT_PHONE_MATCH'))
CONSTRAINT ck_3c0e2a701f CHECK (`status` IN ('ACTIVE','SUSPENDED','REVOKED'))
CONSTRAINT ck_employee_link_revoke CHECK ((status='REVOKED' AND revoked_at IS NOT NULL) OR (status IN ('ACTIVE','SUSPENDED') AND revoked_at IS NULL))
CONSTRAINT ck_employee_link_source_actor CHECK (source='WECHAT_PHONE_MATCH' AND bound_by IS NULL)
```

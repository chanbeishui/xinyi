# 原型开发与重建 V6.4

这是单文件离线HTML交互设计，不是uni-app或xinyi生产代码。src包含全部角色页面、公共组件和本地演示模型；部分模块文件名v4/v41/v42仅表示历史代码组织，当前唯一需求为V6.4，不导入旧业务规则。

运行 `python build.py` 生成index.html；执行 `python export_screens.py` 使用Chromium/Playwright同源导出。修改catalog源时同步03画板索引与01页面规格，再执行包检查。截图没有单独手绘版本，不引用旧zip。

主业务链、勾选组单、行内核价和付款演示继续保留；D39–D46/B43–B45补培训、考试、处罚申诉和活体会话；U02显示本人的自动关联结果；B25/B26直接预配置员工站点，B36只查询和处理关联异常。供应商调用、身份、支付、照片内容全部模拟且有提示，不能用演示固定凭证上线。

# 工具说明

- check_package.py：只读语义与结构一致性检查（输出本包09结果）；不能替代数据库执行。
- contract_tests.py：用JSON Schema转换后的OAS模型与公开快照夹具做正负样本/参考投影策略测试；不是实际HTTP调用。
- verify_mysql.py：用户提供mysql客户端/明确测试库/受控defaults文件后，只读比较information_schema；本轮未执行。
- rebuild_markdown_html.py：Markdown重新渲染离线HTML；UI和流程图另外生成。
- 02_UI/build.py/export_screens.py：源码拼接与实际浏览器截图；导出会覆盖同名图。
- 02_UI/test_v42_*.py：沿用的回归脚本文件名，本轮读的是本包V6.0/index.html，不调用旧zip。
- 02_UI/test_v5_flows.py：新增培训/申诉/凭证/活体演示流程验证。

依赖环境应固定在CI中：Python PyYAML/jsonschema/mistune，浏览器测试Playwright＋Chromium，TypeScript tsc，纯Java例子JDK17+。工具不安装依赖，不自动升级框架。外部资料与参数的有效性仍需真实供应商核验。

组件状态的统一词表

输入：默认 → 聚焦 → 已填 → 错误 → 修正。提交：可提交 → 提交中 → 成功/可重试失败/结果未知/版本冲突。列表：加载中 → 有数据/空数据/失败/无权限。审核：待审 → 已批准待执行/驳回 → 执行中 → 办结/待核实。对账：草稿 → 待本人核对 → 有差异 → 重新发出或确认 → 只读。付款凭证：待复核 → 已核实/驳回，错误不能物理删除。

页面规范与原型实现差异

全量画板提供每个有效页面及关键状态样本；通用列表的基础分页/查询、表单、审核、交接、对账等有内存交互。导出、微信授权、支付、地图、上传和OCR只做明确的本地模拟。未实现所有生产版工作流自动回滚、离线草稿加密、后台真正轮询、完整读屏矩阵或所有深色组合；不能把视觉状态样本计为已运行的端到端测试。

特定原型状态可通过外层画板导航打开，属于评审样本；实际业务流程应从“流程演示”起点依次操作。外层导航与小程序真实角色切换相互独立。

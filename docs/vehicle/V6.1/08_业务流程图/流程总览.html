F02 统一登录与三角色切换

U01、O29、D01/D05、S01

切换角色只改变视角，不释放司机、不复制账号、不合并越权订单。

F03 员工请求、凭证签发与受控绑定

U02/B36/B25/B26/S21/S22

管理员签发不代表已经绑定；仅本人消费成功才建立关联。

F04 代驾资格申请、审核与复审

D02–D05/D28、B16

员工不免审；申请草稿不是已认证。未接入的验证能力不能以模拟通过替代生产核验。

F05 低门槛预约与车辆地址复用

O02/O04/O05/O32/O33/O34/O27/O29–O34

页面编号不是步骤顺序；O32→O33→O31→O34，已有车辆可预填。先选时段不保证名额。

F06 车型字典与计价方案发布

B20/B33、O31/O34

无价格不能默认0元；报价前可重算，已建单价格不因后台改价而改变。等待费启用见P02。

F07 可服务校验与双名额预占

O32/O32/O34、S17、B19

时段展示不锁额，报价不锁额；本图双名额设计属于P04，容量参数需实际运营配置。

F08 支付、30分钟关闭与晚到回调

O10–O13、S04、B31

30分钟不延长；渠道未知不误称“未扣款”。晚通知按可信支付时间和名额实际状态处理。

F09 未来预约计划派单与参数修改

O12/O14、B05/B24

已接单和已接车订单不得被配置变更再次派单。重算既有单必须单独确认，不静默变动。

F10 自动轮转、扩圈与人工兜底

D06–D08、B05/B06

5分钟总上限优先，不能等待50人各60秒再宣称5分钟兜底。人工不可绕过资格和占用。策略见P01。

F11 代驾取消承接与原单重派

D09–D13/D31–D35、B05

取消的是司机任务，不是车主订单；不得产生退款或重新收费。取消与接车并发只能一个成功。

F12 未接车取消与退款·一次审核

O19/O21、B13/B14

若审批时车辆已经接走，切入F13或返回版本冲突，不按申请时快照释放司机。

F13 已接车取消·先返还后办结

O19/O21、B14、D19–D25、S13

取消返还不要求虚假检测结果；司机释放不等待到账。返还后退款执行时点是本版实施默认，待模块评审。

F14 车主向代驾接车交接

O35、D09–D13

“到达”不消耗接车码；司机详情不返回车主持有的码。码只有交接事务成功才被消费。

F15 检测点收车与行驶证核验

S07/S08/S10、B07/B08

“检测中”是订单业务阶段，不等于已经执行某一机器测试。收车码不泄露给核验员工。

F16 检测结果登记与更正

S11/S12、B11/B30、O18

无独立开始/结束检测API；不提供报告PDF上传。未检测的取消单不能伪造PASS或FAIL。

F17 检测点向代驾放行取车

D19/D20、S13

同一交接不由一个账号双向自证，见P03。取消单不要求先写检测结果才能取回车辆。

F18 实际归还、释放司机与后续确认分离

D22/D23/D25、O22/O35

上传照片、发送归还通知、后台审核通过，均不是实际交还。释放不抹掉历史司机关系。

F19 服务确认、争议与自动完成

O22/O23、B15

交还确认与认可服务质量分开；完成不自动推定免除一切责任。争议不重新锁司机。

F20 统一售后申请与退款执行

O19/O21、B13/B14/B31

批准金额为0时不创建退款单。仅退款不取消订单。渠道未知不是失败，不换号重退。

F21 普通服务异常、拒收与失联

D24/D35、S14、B15

不设计事故上报、报警派遣、保险理赔、救援赔付。现实无法继续的处置由线下运营承担，系统不能把未知保管情况写成已还。

F22 照片上传、里程、封存与授权查看

O16、D12/D15/D19/D22、B04

水印可防随意修改，不证明GPS绝对真实；服务端记录采集时间和接收时间，不改写其含义。

F23 通知、失败重试与人工待办

S19、B21、各角色待办

支付和交接事务不因通知失败回滚；过期邀约不因消息重试重新有效。

F24 营业时间、容量、停约与配置变更

S16/S17、B17/B19/B24

不能把容量改小后抹掉已承诺预约；复杂设备实时监控不在本期，只保留人工停约与容量设置。

F25 后台查询、敏感查看与导出

B01/B03/B22/B27/B28

后台角色无站点授权时不可默认为全部；需要全平台范围必须显式授予。

F26 隐私授权、账号退出与删除请求

O28/U03、后台隐私请求入口

个人资料保留策略是上线核验事项，未批准不能宣称永久保存。退出不抹掉已成立的履约责任。

F27 服务记录、评价与再次预约

D25/D27、O25/O26、B23/B28

司机服务记录不显示可提现/待结算；“交还任务数”和“订单已完成数”必须分开统计。

F28 定时任务补偿与旧事件防护

B24/B31、研发监控

Redis失效不能取消数据库唯一性；任务重跑不重复收款、派单、返还或退费。

F29 开发、联调、灰度与回滚

研发与运营

未授权不操作生产数据库、不自动发送真实支付退款。SQL为参考设计，先完成新业务初始化演练。

F30 运营指标与供给校准

B02/B23/B19

500单/日可作为软件压测目标，不自动成为50名司机可实现的运营产能。

F31 司机占用状态与归还后再接单

D06/D23、调度服务

并发与重试必须以occupancy.holderId精确匹配；旧订单自动完成不能误释放当前新订单。

F32 个人对账内核价与整单复核

B28/B37/B42/B38、D37/D38

NULL可进草稿，不可发出。多行改价一张账单复核；确认绑定版本，历史不覆盖。 明确成员集合组单，剩余服务保留待对账。

F33 撤回、差异处理与确认后调差

B38/B41、D38

原账金额/付款不被覆盖。差异说明不自动改钱；新版本未经必要复核不能发送。

F34 费用规则与行内核价关系

B39、B38

改本次拟价不改变全局规则和客户收费。真实费率、取消补偿仍需业务确定。

F35 账单级付款凭证与部分付款

B42/B38/B40、D37/D38

凭证登记不等于付款核实；不自动打款、不自动分摊至单次服务。

F36 工作副本、发布快照与确认结转

ADR-07 / TX28–32 / B38 / D38

技术实现设计：60→70→65最终只结转+5；草稿阶段不重复入账。

F37 双认证域与小程序会话切换

T3.1 ADR-01 / U01/U02/S21

不能把vi_account.id=1当框架超管。员工撤权不注销车主，基础会话仍可切回OWNER。

F38 部门、站点与费用主体组合授权

T3.1 ADR-02/07 / B26/B38/B40

不使用部门OR站点的并集。能看一张站点订单不代表能看司机跨主体全部报酬。

F39 明确勾选组单与草稿成员管理

B42/B38、POST statements、TX16/TX36–38

旧日期生成接口不得在后台默默补选。已确认未付款仍被分配，不可再次组单。

F40 个人未结清、历史账单与付款投影

B42、D37/D38、read model

未结清不等于未组单；只按可信账单和付款事实派生，不能手工改一个已结算字段。

F41 培训课程、学习与考试尝试闭环

D04/D39/D40/D41/D42/B43/B44

播放心跳不证明理解；演示完成不能用作真实资格通过。

F42 限制记录、申诉与公开结果

D31/D32/D33/D43/D44/D45/B45

原普通取消规则，不增加事故/保险或自动扣款处罚。

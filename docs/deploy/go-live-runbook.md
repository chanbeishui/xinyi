> 现状：服务器已定（阿里云轻量 2C4G + 1Panel），但**域名 ICP 备案未下**、**小程序备案未下**。
> 本文按「现在能做什么、被卡住什么、备案下来后怎么切」编排，与
> `docs/deploy/1panel-2c4g-deployment.md`（服务器/数据库详细步骤）配套使用。
>
> 一句话结论：**除了「小程序正式发布」和「微信支付真实扣款」，其余全部链路现在就能上线跑通并验收。**

## 0. 备案到底卡住了什么

| 事项 | 未备案时 | 现在能做 | 备案后 |
|---|---|---|---|
| 域名访问服务器 | 境内服务器 **80/443 被拦截**，域名无法解析访问 | ✅ 用 `IP:8081` 过渡访问 | 切域名 + 443 |
| 小程序请求你的后端 | 域名**加不进**「request 合法域名」白名单 | ✅ 开发版/体验版勾「不校验合法域名」可跑 | 加白名单后正式版可跑 |
| 小程序代码审核/发布 | 微信要求先完成小程序备案 | ❌ 只能到体验版 | 提审 → 发布 |
| 微信支付（真实扣款） | 支付授权目录/回调必须是已备案 HTTPS 域名 | ⚠️ 只能测到下单前的链路 | 配置后真机联调 |
| 短信下发 | 与备案无关，需要签名/模板审核 | ✅ 可完整验证 | — |
| 订阅消息 | 与备案无关 | ✅ 可验证（模板需申请） | — |
| 微信登录 `code2session` | **后端出网调用，不需要备案** | ✅ 可验证真实登录 | — |

关键区分：**「你的服务器被微信前端访问」要备案；「你的服务器访问微信」不要备案**。

## 2. 今天（第 0 天）就做的三件事

### 2.1 域名注册 + 实名认证

- 在阿里云买域名（`.com` / `.cn` 均可）
- **必须完成实名认证**，且实名信息与备案主体一致；实名生效有延迟，未生效无法提交备案
- 域名注册商必须是工信部批复的（阿里云自营域名天然满足）
- 建议同时买下 `.com` 和 `.cn` 防抢注，只有主域需要备案

### 2.2 阿里云 ICP 备案

入口：阿里云控制台 → 备案。准备材料：

- 主体证件（营业执照 / 法人身份证）
- 网站负责人身份证 + 手机号（需人脸核验）
- 域名证书
- **备案服务号**：轻量应用服务器可申请，注意实例剩余时长通常需满足 3 个月以上
- 网站名称、服务内容（别写"预约""平台"这类易被要求前置审批的词，按实际业务描述，如"机动车检测预约服务"）

时间：阿里云初审 1~2 天 → 管局审核通常 7~20 个工作日（各省不同，以控制台进度为准）。

### 2.3 微信小程序备案

入口：微信公众平台 → 设置 → 基本设置 → 小程序备案。

- 主体信息要与小程序认证主体一致
- 需负责人人脸核验
- 备案通过后再提交代码审核，否则审核会因"未备案"被拒

同时把**微信认证**办掉（手机号快速验证、微信支付都依赖认证主体）。认证与备案是两件事，可并行。

## 5. 第三阶段：前端临时站点（半天，IP + 8081）

用 `deploy/prod/nginx-xinyi-temp.conf`，要点：

- `listen 8081`，`server_name _`（不依赖域名）
- `try_files $uri $uri/ /index.html`（刷新子页面不 404）
- `/prod-api/` 反代到 `127.0.0.1:8080/`（**带尾斜杠，剥掉前缀**）
- **建议开启 basic auth + 来源 IP 白名单**：备案期是公网明文 HTTP，后台口令暴露风险高

```bash
# 生成 basic auth（可选但强烈建议）
printf "admin:%s\n" "$(openssl passwd -apr1 '临时口令')" > /home/xinyi/.htpasswd
chown xinyi:xinyi /home/xinyi/.htpasswd && chmod 640 /home/xinyi/.htpasswd
```

访问 `http://公网IP:8081` → 登录 → 走一遍菜单、上传、业务新增。

**本阶段门禁**：后台能用 IP 访问并完成主要业务操作。**不要在这个入口录入真实业务数据**（明文 HTTP）。

## 6. 第四阶段：小程序联调（体验版，1~2 天）

### 6.1 改接口地址

`xinyi-rongli-wx/.env`：

```ini
# 指向公网 IP 的临时站点，末尾不带斜杠
VITE_API_BASE=http://你的公网IP:8081/prod-api
VITE_LOGIN_MODE=mock          # 联调期先用固定演示身份
VITE_LOGIN_CODE=dev_owner_001
```

> 为什么带 `/prod-api`：小程序请求是 `${API_BASE}/api/common/...`，Nginx 会把 `/prod-api` 前缀剥掉，
> 最终打到后端 `/api/common/...`。少写这一段会全 404。

### 6.2 构建并上传

```bash
cd xinyi-rongli-wx
npm run build:mp-weixin       # 产物 dist/build/mp-weixin
```

微信开发者工具 → 导入 `dist/build/mp-weixin` → appid 用 `wx22f41349e671b362`。

### 6.3 跳过域名校验（备案期唯一可行路径）

- **开发者工具**：详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
- **真机体验版**：上传体验版 → 手机打开小程序 → 右上角 `···` → 打开调试 → 重启小程序（出现 vConsole 即生效，此时才忽略域名与证书校验）
- 微信后台 → 成员管理 → 添加体验成员，扫码进入

### 6.4 这个阶段能验证什么

✅ 车主下单、代驾接单、检测完成、后台派单、消息记录落库、上传附件、员工绑定（需真实 AppID/Secret 时在后台集成配置填 `WECHAT_APP`）
❌ 正式版访问、真实支付扣款

> `VITE_LOGIN_MODE=mock` 依赖后端 mock 开关开启；切真实微信登录时两边必须同步改，
> 且 V6.4 规定员工关联**只能**走「微信手机号授权 → 手机号唯一匹配」，短信验证码不能用于关联员工。

## 7. 第五阶段：备案下来后的切换（预留 1 小时窗口）

按顺序做，每步都可回退（先备份 Nginx 配置与数据库）。

1. **域名解析**：A 记录 → 服务器公网 IP，`ping 域名` 确认生效
2. **阿里云防火墙**：放行 `80`、`443`
3. **1Panel 站点**：把站点域名改成正式域名 → HTTPS → 申请 Let's Encrypt（自动续期）→ 开「强制 HTTPS」
4. **换站点配置**：用 `deploy/prod/nginx-xinyi.conf` 覆盖临时配置（443 + 80 跳转 + 反代）
5. **关掉临时入口**：停用/删除 8081 站点，删 `.htpasswd`（否则明文入口一直挂着，等于留后门）
6. **小程序白名单**：微信后台 → 开发管理 → 开发设置 → 服务器域名，加入：
   - `request 合法域名`：`https://你的域名`
   - `uploadFile / downloadFile 合法域名`：同上（附件上传要用）
   > 未备案域名在这一步会被直接拒绝添加，这是备案卡点的真正位置
7. **小程序改配置重新发版**：`VITE_API_BASE=https://你的域名/prod-api`、`VITE_LOGIN_MODE=wechat`，重新 `build:mp-weixin` 上传
8. **微信支付**：商户平台配置支付授权目录/回调为已备案 HTTPS 域名；后台「集成配置」为 **LIVE** 环境填 `WECHAT_PAY`（商户号、APIv3 密钥、证书）与 `PAYMENT_POLICY`
   > V6.4 的 TEST 配置不会打到生产用户，但 LIVE 槽位空着就是"未配置"→ 支付链路按原因码 SKIPPED，不会静默走默认通道
9. **订阅消息**：公众平台申请模板 → 后台绑定 `WECHAT_SUBSCRIBE` 路由与模板 ID
10. **小程序备案通过** → 提交代码审核 → 审核通过发布
11. **公安备案**：ICP 备案通过后 30 日内到「全国互联网安全管理服务平台」办理（多数地区要求）
12. **全链路验收**（见第 9 节）

## 10. 常见卡点

| 卡点 | 说明 |
|---|---|
| 备案被驳回 | 多为：域名实名未生效、主体信息不一致、网站名称含敏感词、服务内容需前置审批。按驳回意见改，不用重排队 |
| 80 端口打不开 | 未备案时这是**预期行为**，不是配置问题；别浪费时间查 Nginx |
| 小程序加不了域名 | 域名未备案时白名单会拒绝；备案通过后 10 分钟~2 小时生效 |
| 体验版真机请求失败 | 没打开「调试」开关，域名/证书校验仍在生效 |
| 支付回调收不到 | 回调地址必须是 HTTPS 备案域名；商户平台与后台集成配置两处要一致 |
| 时间差 8 小时 | 容器 MySQL 的 `default-time-zone` 没设，仍是 UTC |

## 11. 回退预案

- **Nginx**：改动前 `cp 站点.conf 站点.conf.bak-$(date +%F)`，出问题 `openresty -s reload` 回退
- **后端**：保留上一个可用 jar（`xinyi-admin.jar.bak`），`systemctl restart` 即回滚
- **数据库**：切换前手动跑一次备份脚本，出问题可整库恢复
- **前端**：`dist` 保留上一版目录（`web.old-<日期>`），改 `root` 指回去即可
- **小程序**：保留上一版代码包，后台可回退到上一线上版本

## 12. 备案期内不要做的事

- 不要用未备案域名解析到境内服务器（会被拦截，也可能影响备案核验）
- 不要在公网明文入口录入真实业务数据（车牌、手机号属个人信息）
- 不要把 8080/3306/6379 开到公网"图方便"
- 不要等备案下来才开始装环境（技术流程与备案完全并行）

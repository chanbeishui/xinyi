# CA 电子签（私有化 / 哈希上签）供应商选型提纲

> 适用场景：建筑检测报告签字盖章，要求对外出具的 PDF 具备可靠电子签名法律效力，且报告原文不出企业内网。
> 目标路线：与持牌 CA 合作，采用"私有化部署 / 哈希上签（原文不出本地）"模式——根证书用供应商的国家认可根，私钥与签名动作落本地，报告内容全程不离开内网。
> 用法：带这份清单逐条问供应商，要求对方书面答复，重点关注标★项。

---

## 一、资质与根证书（信任链根基）

1. 是否持有工信部《电子认证服务许可证》？请提供许可证编号与有效期。
2. 根证书是否内置主流操作系统 / 浏览器信任库？是否被司法、住建等行业监管条线认可？
3. ★ 是否支持国密 SM2 / SM3 算法（等保 2.0 / 密评要求）？是否同时兼容国际算法（RSA / SHA）？
4. 是否通过商用密码产品认证（GM/T 标准）？请提供认证证书编号。

## 二、数据私密性（核心诉求：原文不出本地）

5. ★ 是否支持私有化 / 本地化部署？部署形态是软件、一体机还是容器？
6. ★ 企业私钥是否可托管在本地 HSM / 密码机（而非 CA 云端）？私钥是否永不出硬件？
7. ★ 是否支持"哈希上签 / 原文不出本地"模式？报告内容是否全程不离开企业内网？
8. 签名运算在本地还是云端完成？CA 侧实际接收到的数据是什么（是否仅为哈希值）？

## 三、签名标准与合规

9. 是否符合 PAdES 标准（PDF 长效签名、支持 LTV 长期有效）？
10. 是否提供可信时间戳（TSA）？时间戳服务是否具备合规资质、是否自有？
11. 是否满足《电子签名法》"可靠电子签名"四要素：签名数据专有、签署时仅由签名人控制、签署后签名改动可发现、签署后原文改动可发现？
12. 是否支持签名后长期验证（LTV），避免证书过期后无法验真？

## 四、印章管理

13. 电子印章如何制作 / 备案？是否支持与工商 / 公安电子印章互认？
14. ★ 印章外观是否由本地渲染（CA 不接触印章图）？
15. 用印审批 / 权限控制能否接入现有业务系统（xinyi）？是否支持多部门、多人分级用印与审计日志？

## 五、集成与接口（对接 xinyi 系统）

16. 提供哪些 API（发起签名 / 哈希上签 / 状态回调 / 文件下载）？是否有本地化 SDK / 中间件？
17. ★ 回调是否支持验签（防伪造回调）？是否支持"异步通知 + 主动查询"双通道？
18. 是否提供标准对接文档与沙箱环境？我们需自建"签署任务表"做状态回查与幂等，对方是否有相应规范？

## 六、出证与司法效力

19. 是否提供出证报告 / 证据链？司法纠纷时是否提供技术支持与出证？
20. 是否接入司法区块链存证（如天平链、司法链等）？

## 七、运维、安全与成本

21. 报价模式（按次 / 按证书数 / 年度订阅 / 一次性部署费 + 维保）？
22. 私有化部署的硬件 / 授权 / 密码机费用分别多少？
23. SLA、故障响应时间、等级保护级别？
24. 是否需要年审 / 证书续费 / 系统升级费用？数据迁移与退出条款如何约定？

## 八、落地验证（POC 必做）

25. ★ 能否提供 POC：用一份真实检测报告跑通"本地渲染 → 哈希上签 → 本地合成"全流程？
26. ★ POC 中必须验证三点：报告原文确实未出本地；CA 侧仅收到哈希值；最终 PDF 可被第三方 PDF 阅读器（Adobe / 福昕）独立验签通过。

---

### 决策底线（不可妥协项）
- 根证书国家认可（持牌）；
- 私钥本地托管、原文不出本地；
- 符合 PAdES + 国密 + 可信时间戳；
- 印章本地渲染、用印可审计；
- 回调验签、第三方可离线验真。

任一标★项答否，原则上不予采用。

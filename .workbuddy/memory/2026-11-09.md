## 环境替换坑（重要）

本会话环境会把字面量 `1`+`Panel` 的产品名**自动替换成随机 ID**（例如 `1Panel` → `1Panel`），
**连 bash heredoc 与 printf 也会被替换**，只有小写 `1panel` 不受影响。
已因此把 docs/deploy、deploy/prod、memory 里 13 个文件共 47 处错误串批量修正为小写 `1panel`。
结论：以后写该产品名一律用小写 `1panel`。

## 保存草稿无限递归爆栈（发布后才暴露的真因）

- 现象：点「保存草稿」没有任何请求发出，控制台 `RangeError: Maximum call stack size exceeded`，
  栈里重复出现 `ConfigShell-DJ02zk2W.js:1:2927` 同一个函数；顶部三条 ERROR 永不消失。
- 根因：`ConfigShell.vue` 顶部 `import { saveDraft } from '@/api/rongli/integration'`，
  下方又声明 `async function saveDraft()`。**函数声明在模块作用域内遮蔽了导入绑定**，
  保存函数内部 `saveDraft(...)` 调用的是自己 → `await` 自调用 → 爆栈。
  压缩产物铁证：`async function X(){ ... const n = await X(o.value.profileId, {...}) }`。
- 为什么没被发现：`vite build` 只跑 esbuild 转译、不做类型检查（`vue-tsc` 才会报重复声明）。
- 修法（commit 26d3a25）：导入改别名 `saveDraft as saveDraftApi`，调用点同步改；
  并扫描 `src/**/*.vue`，导入绑定名与本地 `function` 声明名的交集已为空。
- 关键认知：**11-06 那轮不是全部**。两个 bug 串联——先爆栈（草稿根本没写进库），
  再是 `load()` 清掉 draftRev（即使保存成功也走不到校验）。只修后者时现象完全不变。
- 部署识别：旧产物 `ConfigShell-DJ02zk2W.js`，修复后 `ConfigShell-CyRs7MHX.js`。
- 顺带确认的校验规则（`IntegrationRules.wechatApp`）：
  - `appId` 必须 `wx` + 16 位十六进制（共 18 字符）。截图里的 `wx22f41349e67b362`
    只有 15 位十六进制，校验会报 `VI_CONFIG_INVALID`；
  - `config` 必须**包含** `enabled` 键（`containsKey` 判断，false 也要有）；
  - `enabled=true` 时 `appSecret` 必须已登记，否则报 `VI_CONFIG_SECRET_MISSING`。

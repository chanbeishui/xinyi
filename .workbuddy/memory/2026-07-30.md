## 档案室页面空白 Bug 修复
- **根因**：constantRoutes 中 `/dataScreen` 和 `/archiveRoom` 的路由 `name`（`DataScreen`、`ArchiveRoom`）与数据库动态路由生成的同名路由冲突。更严重的是，菜单 2025 (path=index) 后端生成 `name: "Index"`，与 constantRoutes 首页路由 `name: "Index"` 冲突——Vue Router 4 的 `addRoute` 会移除同名已有路由，导致首页路由被删除、档案室路由被错误替换。
- **修复**（3 个文件）：
  1. `src/router/index.ts`：删除 `/dataScreen` 和 `/archiveRoom` 的 constantRoutes（数据库已有对应菜单，动态路由会生成）；首页路由 `name` 从 `'Index'` 改为 `'Home'`
  2. `src/components/Breadcrumb/index.vue`：`isDashboard` 检查从 `'Index'` 改为 `'Home'`
- **关键排查路径**：后端 `SysMenuServiceImpl.getRouteName()` 将 menu path 首字母大写作为路由 name → `route_name` 字段为空时 fallback 到 path → `capitalize("index")` = `"Index"` → 与首页路由名冲突

## ArchivePlan.vue zoneColor 运行时错误修复
- **错误**：`Uncaught TypeError: _ctx.zoneColor is not a function` at ArchivePlan.vue:41
- **根因**：模板第 41 行调用 `zoneColor(cab.zone)`，但 script 中将导入的 `zoneColor` 重命名为了 `findZoneColor`（`import { zoneColor as findZoneColor }`），模板里找不到 `zoneColor` 函数
- **修复**：在 script 中新增 `function zoneColor(zone: string)` 包装函数，调用 `findZoneColor(zone, props.zoneConfigs)`，同时 `zoneColorWithOpacity` 也改为复用此函数

# 2026-07-22 工作日志

## 前端外观模式切换功能

在布局设置面板中新增"外观模式"选择，支持浅色/深色/跟随系统三种模式。

### 改动文件
- `xinyi-ui/src/store/modules/settings.ts` — 将 `useDark/useToggle` 替换为 `useColorMode + usePreferredDark`，新增 `colorScheme` 状态字段和 `setColorScheme` action，`isDark` 改为 getter（响应式计算）
- `xinyi-ui/src/settings.ts` — 新增 `colorScheme: 'auto'` 默认配置
- `xinyi-ui/src/layout/components/Settings/index.vue` — 在主题风格设置区域上方新增"外观模式"区域（el-radio-group: 浅色/深色/跟随系统），保存配置时包含 `colorScheme` 字段

### 技术要点
- VueUse `useColorMode` 支持 'auto' 模式，自动跟随系统 `prefers-color-scheme`
- `isDark` getter 通过 `usePreferredDark` + `computed` 保持响应式，确保现有组件的 `watch` 和 `computed` 正常工作
- 持久化：`colorScheme` 存入 `layout-setting` localStorage，同时 VueUse 自动管理 `vueuse-color-scheme` key

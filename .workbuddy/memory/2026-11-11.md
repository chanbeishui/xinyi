## 检测点地址改为省市区下拉（commit ed2e469 / 4587a46 / 8bbfc7e）
- 行政区划数据**不入库也不入仓**：`utils/region.ts` 用高德
  `DistrictSearch({ level:'country', subdistrict:3 })` 一次取全国三级树，压成
  `{省:{市:[区]}}` 存 localStorage `rongli.region.tree.v2`（TTL 30 天）。
  静态表（两三千条）进仓库会很快过期，还得手工维护撤县设区。
- **直辖市补一层同名市**：高德把区县直接挂在省级（或只套一层「市辖区」），
  不补的话市级下拉会出现一堆区名；`onlyOnePlaceholder` 分支处理「市辖区」包装。
- **拆分用「按后缀切词」而不是 startsWith**：`/^(.{2,}?(?:省|自治区|特别行政区))/`
  这类正则先切出 token 再精确比对；startsWith 会把「吉林市」吃成「吉林省」。
- **拼接去重**：`joinAddress` 逐个剥掉 detail 开头与已选行政区重复的前缀。
  简称（去掉省/市/区后缀）只在「后面紧跟另一个已选行政区」时才认，
  否则「海南路1号」会被当成「海南省」；吉林省 vs 吉林市不能合并，
  所以同名合并要求两边都以「市」结尾（直辖市）。
- 编辑旧记录：`splitAddress` 回填三个下拉；老数据不写省（「茂名市茂南区…」）
  时按市级反查归属省；拆不出来整串留在 detail，信息不丢。
- 取不到行政区划（没配 Key）时下拉置灰 + 提示条说明，详细地址仍可手写完整地址，
  不阻塞录入。

## 外部接口额度/权限错误必须直说（commit 237ad95 / 95857b3）
- 用户明确要求：外部 API 出现调用次数限制时，提示语要**直接写给用户看的原因和动作**，
  例如额度用尽必须是「高德地图基础LBS服务每月使用额度已达上限，请技术人员扩容」，
  不能兜成「服务暂时不可用/加载失败」——运营会反复重试，能处理的人却看不到信号。
- 落地：`utils/amap.ts` 的 `amapErrorMessage(result)`，按 `infocode` 查表（兼认只带
  `info` 的回调，`AMAP_ERROR_CODES` 做 info→code 映射）。额度类 10003/10044/10045、
  `DAILY_QUERY_OVER_LIMIT`/`OVER_QUOTA` 统一走 `QUOTA_MESSAGE`；表里没有的新码若语义仍是
  `*_OVER_LIMIT|QUOTA`，按额度提示兜底，其余保留原始 info/infocode 便于排查。
- 串接点：Geocoder/PlaceSearch `status==='error'` → 写状态条并**跳过兜底检索**
  （服务级错误重试只会再错一次）；DistrictSearch 失败把原始原因抛给抽屉提示条；
  脚本 `onerror` 说明可能是 Key/白名单/额度；地图彻底起不来时用 `.map-picker__mask`
  把原因铺在画布上，不只留一行小字。
- 该约定已写进 `AGENTS.md`「安全与配置提示」，新增外部服务（OSS、短信等）照此补码表。

## 代驾费用试算恒为 ¥0.00（commit e7c6862）
- 现象：代驾费用规则 → 试算 10 公里，结果永远「本次试算应付 ¥0.00」。
- 根因：前端读错返回字段。`LedgerService.trialFee` 返回的是 `amountFen`，
  前端写的是 `res?.feeFen ?? res?.totalFen ?? 0`，两个字段都不存在 → 恒落到 0。
  **后端算法正确**：4000 + ceil((10000-8000)/1000)×500 = 5000 分 = 50 元。
- 修复：改读 `amountFen`，并展示拆分（基础费 + 超出里程 × 单价），方便当场核对。
- 本地规则参数（`vi_driver_fee_rule.pricing_json`，核算基准）：
  `NORMAL_RETURN` baseFen=4000 / includedMeters=8000 / unitMeters=1000 / unitPriceFen=500；
  `CANCEL_RETURN` baseFen=2000 / unitPriceFen=0。
- 教训：这类「前端字段名猜错」不会抛错，只会静默显示 0；先看 Network 的实际响应字段，
  别从 UI 反推。

## 提交信息里的反引号会被 shell 吞掉
- `git commit -m "...\`res?.feeFen\`..."` 在 Git Bash 下反引号被当命令替换，
  正文那段直接消失，还会打印 `command not found`。
- 规避：正文含反引号或 `$` 时，用 Write 写消息文件，再 `git commit -F <file>`
  （这次用 `--amend -F` 修正过）。

# 2026-11-13 侧栏导航整理：首页合并 + 系统目录收口

## 结果

一级目录从 5 个降到 3 个：`首页`（前端静态路由）→ `车辆检测预约`（2100，order 1）→ `系统管理`（1，order 2）。
`系统监控`(2)、`系统工具`(3) 变成 `系统管理` 的子目录；`运营工作台`(2115) 从侧栏隐藏，页面并入 `/index`。

## 关键约束：子菜单必须用绝对路径

系统监控挂到系统管理下时，`path` 写 **`/monitor`**（带前导斜杠），不是 `monitor`。

- 后端 `getRouterPath()` 只对「一级目录」加前缀；子目录原样返回，所以绝对路径能穿过。
- 前端 `filterChildren()`（`filterAsyncRouter(type=true)`）会把 ParentView 子项按
  `lastRouter.path + '/' + el.path` 拍平到父级 children：`/monitor` + `/online` = `/monitor/online`，
  Vue Router 4 允许嵌套绝对路径，URL 不变。
- 若写相对路径 `monitor`，URL 会变成 `/system/monitor/online`，
  `router/index.ts` 里 `meta.activeMenu: '/monitor/job'`、首页快捷入口、历史收藏全部失效。
- **侧栏还要单独适配**：`SidebarItem.resolvePath()` 原来无条件 `basePath + '/' + routePath`，
  会把 `/monitor` 拼成 `/system/monitor`。已加「以 `/` 开头直接当绝对路径」分支。

## 父级变更会导致整棵子树消失

侧栏按父子树渲染，`selectMenuTreeByUserId` 从 `parent_id = 0` 开始建树。
只授了「系统监控」而没授「系统管理」的角色，改父级后菜单直接不见（不是报错，是静默消失）。
迁移里 `INSERT IGNORE INTO sys_role_menu SELECT DISTINCT role_id, 1 FROM sys_role_menu WHERE menu_id IN (2,3)` 兜住。

## unique-opened 必须为 false

`Sidebar/index.vue` 原本 `:unique-opened="true"`，点开一个目录会收掉其它目录，
三层菜单下表现为「刚展开系统监控，业务处理就合上了」。改 false 后可同时展开任意多级。
Element Plus 的层级缩进与收起态的多级浮层都自动支持，不需要额外 CSS。

## 首页合并的做法

- `/index`（`views/index.vue`）为唯一实现；`views/rongli/dashboard/index.vue` 退化成
  `<Home />` 薄壳，旧地址 `/rongli/business/dashboard` 仍可打开。
- 整块运营内容以 `biz:statistics:list` 为开关（`auth.hasPermi`），无权限只显示欢迎条 + 系统入口；
  当日预约表再单独判 `biz:order:list`，否则只有统计权限的角色拉订单接口会 403 弹错。
- 指标卡取 `statistics.overview`（orders_today / aftersale_pending / cancel_return_waiting /
  statement_pending），待办取 `overview` + `dashboard.dispatching`，趋势图取 `statistics.last7`。
- 删掉了首页原来的假数据（访问量/在线用户/新增用户/访问来源/更新日志），避免和第二份数据打架。

## 窄屏坑：指标卡标签被压成竖排

`icon + label/value + 待处理标` 三列在 390px 两列布局下会把标签挤到十几个像素，
「售后待审」逐字竖排。修法：标签 `nowrap + ellipsis`，≤768px 隐藏「待处理」标与箭头
（`.stat-alert/.stat-go`），图标 46→36、数值 24→20。

## 本地怎么验证后台页面（无后端时）

`npx vite build --outDir dist-verify-xxx` → `python -m http.server` → Playwright
（`C:/Users/Administrator/AppData/Local/npm-cache/_npx/e41f203b7505f1fb/node_modules/playwright`，`channel: 'msedge'`）
+ `context.addCookies([{name:'Admin-Token', value:'mock', url: base}])` + `page.route('**/prod-api/**')`。

**mock 结构必须分清两种返回**：
- `/getInfo` 是**扁平**结构（`{code, user, roles, permissions}`），不是 `{code, data:{user}}`；
  包错会在 `user.avatar` 报 undefined，然后守卫 catch → logOut → 回到登录页，现象很像「token 失效」。
- `/getRouters` 与 `AjaxResult.success()` 类接口是 `{code, data}`；荣利 `/api/admin/*`
  控制器直接返回 Map，**body 就是数据本身**（`{overview, dashboard}`、`{rows, total}`）。
- 深链不能用 `page.goto('/rongli/...')`：`python -m http.server` 没有 history 回退，会 404。
  用 `history.pushState` + `dispatchEvent(new PopStateEvent('popstate'))` 走客户端路由。

### 发现：小程序凭据有两套存储（会卡真实登录）
- 后台「订阅消息」页（menu 2143 `subscribe` → `rongli/configSubscribe/index`）保存时经
  `SubscribeConfigService` 写 `sys_config` 的 `rongli.mini.appId` / `rongli.mini.appSecret`（ENC 密文）
- 后台「第三方服务 → 小程序公共凭据 B53」（menu 2248 `wechatApp`）写集成档案 `WECHAT_APP`
- `WechatMiniClient` 只读 `BizConfig` → `sys_config`，所以**登录/手机号解析只认「订阅消息」页填的值**；
  B53 只被 `IntegrationSubscriptionService` 用于订阅消息发送
- 现状：`sys_config` 两键均为空 → 真实登录必然报「未配置小程序 AppSecret」
- 修法二选一（待定）：① 文档里要求两处都填（已在 doc 10.1.1 写明）；② 给 `WechatMiniClient`
  加回落：sys_config 为空时取已发布的 `WECHAT_APP` 档案

### 关键约束（真机 vs 发布）
- 预览 / 真机调试（开发版）：可走局域网 http，`project.config.json` 已 `urlCheck=false`
- 体验版 / 正式版：**必须已备案的 HTTPS 域名**并在后台配 request 合法域名，局域网地址无效
- 手机号快速验证组件要求小程序主体已微信认证；隐私保护指引必须声明收集手机号
- 2023-09 起小程序需 ICP 备案才能发布

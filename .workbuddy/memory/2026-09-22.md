## MySQL 本地环境配置（Windows）
- 真实安装目录：`D:\Program Files\MySQL\MySQL Server 8.0\bin`（8.0.41 社区版），`mysql`/`mysqldump` 均在此。
- 系统(Machine) PATH 里有一条坏记录 `Program Files\MySQL\MySQL Server 8.0\bin`（无盘符、指向不存在的 C: 路径），无害但冗余，待清理。
- 已将正确的 Server bin 目录加入**用户级 PATH**（用 `setx` 写入；`[Environment]::SetEnvironmentVariable` 在本沙箱被静默丢弃，须用 `setx`）。
- 服务名 `MySQL80`，`my.ini` 端口 `3307`，`defaults-file=D:\ProgramData\MySQL\MySQL Server 8.0\my.ini`。
- 排查 `ERROR 2003 (HY000) / 10061`：根因是 `MySQL80` 服务处于 Stopped，用 `Start-Service MySQL80` 拉起后 3307 端口 `TcpTestSucceeded=True`，连接恢复正常。
- 连接命令：`mysql -h 127.0.0.1 -P 3307 -u root -p`（密码 chenbeishui）。
- 注意：若服务启动类型为 Manual，重启后需重新 `Start-Service MySQL80`；如需开机自启可改为 Automatic。
